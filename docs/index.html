Video overview

Generated Package

A versioned ProjectSpec declares reusable asset types, placed occurrences, IFC classes, systems, ports, connections, artifacts, and required coverage. A separate reconciliation contract binds those values to producer inputs without copying expected geometry. The v1 evidence verifies supported input plumbing and current CadQuery parameter sensitivity; exact dimensional inspection of committed exports remains a separate milestone.
