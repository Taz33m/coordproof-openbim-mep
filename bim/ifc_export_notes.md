# IFC Export Notes

The primary OpenBIM deliverable is:

```text
bim/mechanical_room.ifc
```

This file is generated by `tools/openbim_core.py` with IfcOpenShell and is the
semantic source of truth for the project. FreeCAD, STEP, STL, DXF, and PDF files
remain important review/export artifacts, but the OpenBIM scope is validated
against this IFC model.

Target hierarchy:

```text
IfcProject
IfcSite
IfcBuilding
IfcBuildingStorey
IfcSpace
```

The model uses specific IFC4 MEP classes where the semantic scope depends on
them, including:

```text
IfcUnitaryEquipment
IfcFilter
IfcCoil
IfcFan
IfcPump
IfcPipeSegment
IfcPipeFitting
IfcValve
IfcSensor
IfcDuctSegment
IfcDamper
IfcAirTerminal
IfcCableCarrierSegment
IfcMechanicalFastener
IfcVirtualElement
```

Distribution systems are modeled with `IfcDistributionSystem` and
`IfcRelAssignsToGroup` for CHWS, CHWR, supply air, return air, and electrical
routing. Equipment and flow components include `IfcDistributionPort` objects and
`IfcRelConnectsPorts` relationships so the IFC is inspectable as a connected
MEP network, not just named geometry.

Validation fails if the IFC falls back to generic `IfcBuildingElementProxy`
objects for the semantic MEP scope.
